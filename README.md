# 울산광역시피클볼협회 회원인증 웹앱

클럽 회원인지 아닌지 확인해주는 간단한 인증 웹앱입니다.
회원 명단은 구글시트에 있고, 화면은 GitHub Pages로 열리고, 실제 대조(확인) 작업은 구글 앱스크립트가 처리합니다.

## 어떻게 동작하나요?

1. 사용자가 웹페이지(`index.html`)에서 이름/생년월일/전화번호 뒷자리를 입력합니다.
2. 이 웹페이지는 그 정보를 구글 앱스크립트가 만든 "웹앱 주소"로 전송합니다.
3. 앱스크립트(`apps-script/Code.gs`)가 구글시트의 회원 명단과 대조해서 결과(정회원/준회원/정보없음 등)를 돌려줍니다.
4. 웹페이지가 그 결과를 화면에 보여줍니다.

즉, 두 부분이 서로 다른 곳에서 실행됩니다.

| 부분 | 실제로 어디서 돌아가나 | 이 저장소에서의 위치 |
|---|---|---|
| 화면 (HTML) | GitHub Pages | `index.html` (루트에 있어야 함) |
| 인증 로직 | 구글 앱스크립트 (구글시트에 연결된 스크립트 편집기) | `apps-script/Code.gs` (참고용 보관본) |

## 폴더 구조

```
index.html                  → 화면 원본 (앱스크립트 주소 자리엔 __GAS_WEB_APP_URL__ 자리표시자만 있음)
.github/workflows/deploy.yml → 업로드할 때마다 자동으로 실제 주소를 채워 배포하는 설정
apps-script/Code.gs          → 앱스크립트 코드의 보관/버전관리용 사본
archive/streamlit-attempt/   → 예전에 스트림릿으로 시도했던 흔적 (현재 사용 안 함)
```

## 코드를 수정한 뒤 실제로 반영하는 방법

**화면(index.html)을 고쳤을 때**
그대로 GitHub에 업로드(커밋)하면 자동으로 실제 사이트가 새로 만들어집니다. (보통 1~2분 내 반영). `index.html`을 직접 여시면 앱스크립트 주소 자리에 `__GAS_WEB_APP_URL__`이라고만 적혀 있는데, 정상입니다 — 실제 주소는 저장소가 아니라 GitHub의 Secret(비밀값)에만 저장되어 있고, 업로드할 때마다 자동으로 채워져서 배포됩니다.

**인증 로직(Code.gs)을 고쳤을 때**
이 저장소의 파일을 수정하는 것만으로는 실제 서비스에 반영되지 않습니다. 구글시트 → 확장 프로그램 → Apps Script를 열고, `apps-script/Code.gs`의 최신 내용을 편집기 안 코드에 그대로 덮어쓴 뒤 저장 → 배포(새 버전 배포)까지 해야 실제로 반영됩니다.

## 앱스크립트 웹앱 주소가 바뀌었을 때 (최초 1회 설정 포함)

앱스크립트에서 배포를 새로 만들어 주소가 바뀌면, GitHub 저장소의 Secret도 함께 갱신해야 합니다.

1. GitHub 저장소 페이지 → **Settings** → 왼쪽 메뉴 **Secrets and variables** → **Actions**
2. **New repository secret** 클릭 (이미 있다면 기존 값 옆의 Update 사용)
3. Name: `GAS_WEB_APP_URL`, Secret: 새로 발급받은 웹앱 주소 붙여넣기 → **Add secret**
4. 저장소 **Settings** → **Pages** → **Build and deployment** → **Source**를 **GitHub Actions**로 설정 (최초 1회만 필요)

## 주의할 점

- `index.html` 원본 코드에는 앱스크립트 "웹앱 주소"가 더 이상 그대로 적혀 있지 않습니다. 다만 실제 사이트를 이용하는 사람은 브라우저 개발자도구(F12)의 네트워크 탭에서 여전히 이 주소를 볼 수 있습니다 — 이는 서버 없이 화면(HTML)만으로 동작하는 모든 웹사이트가 갖는 근본적인 한계이며, 이번 조치는 "깃허브 공개 저장소를 통한 자동 스캔/검색 노출"만 막아주는 것입니다.
- 예전에 노출됐던 주소는 앱스크립트에서 새 배포를 만들고 예전 배포를 보관처리(비활성화)하면 더 이상 동작하지 않게 되어, 과거 커밋 기록에 남아있어도 위험하지 않습니다.
- 회원 개인정보(이름, 생년월일, 전화번호)는 이 저장소 어디에도 저장되어 있지 않습니다. 실제 데이터는 구글시트에만 있습니다.
